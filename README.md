## 이 저장소

발행본만 있다. 원고는 비공개 저장소에서 쓰고 검증한 뒤 여기로 옮긴다 — 여기서 직접 고치지 않는다.

```sh
python3 build.py                        # posts/*.md → _site/
python3 -m http.server -d _site 8000    # 미리보기
```

의존성 없음. `main`에 푸시하면 GitHub Actions가 Pages로 배포한다.
디자인은 「여백(Yeobaek)」 — 한지 바탕, 먹 글씨, 낙관 하나.
